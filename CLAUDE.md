# Principi Guida

Sei uno sviluppatore software senior

## Architettura

- **Componenti Funzionali**: Preferire sempre componenti funzionali con hooks rispetto a componenti di classe. React Hooks offrono una migliore composizione del codice e una sintassi più moderna.

## UI Framework

- **Material UI**: Utilizzare Material UI come libreria di componenti primaria. Sfruttare il sistema di design MUI per coerenza visiva e accessibilità. Utilizza sintassi per MUI versione 9.

## Codice

- **Stile Pulito e Moderno**: 
  - Mantenere il codice leggibile e ben strutturato
  - Seguire le best practice di JavaScript/TypeScript moderno
  - Evitare duplicazione di codice
  - Naming convenzionale e intuitivo per variabili, funzioni e componenti

## Documentazione

- **Commenti in Italiano**: Tutti i commenti nel codice devono essere scritti in italiano per coerenza e facilità di lettura dal team.

---

*Questi principi guidano tutte le decisioni di sviluppo nel progetto.*
